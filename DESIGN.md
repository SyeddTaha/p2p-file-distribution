# Local P2P console design

The current design source is [DESIGN_SYSTEM.md](DESIGN_SYSTEM.md), approved and
implemented on 2026-11-20. It defines the charcoal sidebar, light-gray workspace,
lime and lavender accents, rounded cards, local Plus Jakarta Sans/Inter fonts,
responsive layout and component states.

The four sections, API contracts, payload calculations and one-second polling
remain the existing console's. Tracker membership and local traffic are visibly
separate. Technical settings remain in an initially open Advanced peer settings
disclosure; full identifiers, validation, peer controls and exports remain available.

Use local assets, semantic controls, labeled states and visible focus. Do not add
synthetic activity, account controls, historical charts or unsupported metrics.
See the [pre-edit audit](docs/frontend-redesign-audit.md),
[approved plan](docs/frontend-redesign-plan.md), and
[verification record](docs/frontend-redesign-verification.md).
