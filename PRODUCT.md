# Product

## Register

product

## Users

Computer Networks students and instructors operating a local demonstration in a
classroom or lab. They need to start peers, inspect transfers, verify integrity,
and compare recorded distribution experiments.

## Product Purpose

Provide a small control console for the existing TCP engine. Every displayed peer,
byte count, verification result, and benchmark value must come from that engine
or an identified recorded dataset.

## Brand Personality

Restrained, precise, practical. References are GitHub, Linear, and conventional
developer dashboards, as specified in the project brief.

## Anti-references

No SaaS landing page styling, gradients, glass, decorative illustration, excessive
cards, emoji icons, fake activity, or simulated progress.

## Design Principles

- Prioritize operating and inspecting the network.
- Show the measurement scope and distinguish unknown from zero.
- Use familiar controls, compact tables, and explicit state labels.
- Keep file data on the peer TCP data plane after browser source import.

## Accessibility & Inclusion

Use semantic HTML, visible labels, keyboard focus, text alongside status colors,
and responsive layouts. Respect browser font sizing; do not rely on animation.
